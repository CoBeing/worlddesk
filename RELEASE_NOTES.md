# WorldDesk v0.1.0-preview.1

First public, unsigned WorldDesk desktop preview.

Ready to try:
- World Surprise, public earthquakes, NASA natural events and a map.
- Direct third-party radio stream selection, local bookmarks and source sharing.
- Bundled Local Bridge native executable, no separate install or background service.
- No account or API keys needed for normal use.

Known limitations:
- External sources require network access and can be delayed/unavailable.
- CoBeing sync, social features and God’s Eye View 3D embed are not included.
- Native SDR, messaging, flight feeds and AI Agent actions are not included.
- Files are unsigned and unnotarized; verify checksum before use.

See README.md and docs/PREVIEW_INSTALL.md.
